# bonch-1-2026

Проект сценария «Лунная База v2.4».

- `moonbase.ipynb` — заготовка решения: ноутбук подключается к запущенной симуляции, дальше идут два раздела —
  модуль безопасности (CybP_02–05) и заезд — с короткими подсказками и пустыми ячейками `# TODO`. Код решения
  пишет команда.

Клиент сценария `quasar_client` поставляется вместе с Квазаром и подключается автоматически
(в ноутбуке: `from quasar_client import QuasarClient`); копировать его в проект не нужно.
Решение пишется в `moonbase.ipynb`; другие файлы проекта правьте, только если это явно
разрешено рабочими материалами.

Запускайте ноутбук из Квазара: параметры подключения выдаются только на время активного
проекта и не сохраняются в файлах. Порядок работы — в документе «С чего начать», задачи — в
документах «Задачи робота» и «Задачи кибериммунности», методы клиента и готовые движения — в
документе «Python API участника».
